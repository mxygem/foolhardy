# Foolhardy — handoff notes

A poker roguelike for the browser. Plain JavaScript, no build step, classic `<script>` tags (must work from `file://`, so no ES modules). Original name, theme, joker roster and look — do not copy any existing game's joker names, art or visual style.

## Status

Everything in the original plan is built and passing. Run it by opening `index.html`, or `python3 -m http.server 8765` in this folder and visit `http://127.0.0.1:8765/`. Run the checks with `node test/check.js`.

- [x] `js/core.js` — rules engine
- [x] `js/items.js` — 55 consumables (12 Decrees, 23 Charms, 20 Rites) and 26 bosses
- [x] `js/jokers-a.js` … `jokers-d.js` — 300 jokers (121 common, 138 uncommon, 33 rare, 8 legendary)
- [x] `js/art.js` — procedural SVG art per joker
- [x] `js/ui.js`, `css/style.css`, `index.html` — the interface
- [x] `test/check.js` — all checks pass: 300 jokers; unique names, emoji, flavor and normalized descriptions; each joker alone for several rounds; 7,600 chaos rounds with random joker mixes
- [x] Browser check at 1440×900: blind select, play and scoring replay, cash-out, shop, collection, deck, hand levels, consumable use, discard, face-down boss cards, game over. No console errors.

## Next steps, in priority order

1. **Play it by hand and tune balance.** This is the biggest unknown. The test bot (greedy, buys at random) won 0 of 300 honest runs and usually dies in antes 1–3; it is a weak player, so that is not proof the game is too hard, but nobody has played a full run yet. Levers: `ANTE_BASE` and `FH.BLINDS` in `core.js`, `FH.HANDS` values, joker `cost`, starting money in `newGame`. A smarter bot in `test/check.js` (chase flushes/straights, value jokers) would give a real signal.
2. **Check the things written but not exercised in a browser:** drag-to-reorder for jokers and hand cards, the keyboard shortcuts, the victory screen and endless mode, and the layout under 900px wide (CSS exists, never screenshotted).
3. **Save and resume.** Nothing persists across a reload. State is plain data except `g.rng`, `joker.def`, `cons.def`, `g.boss` and `method_actor`'s `s.sub`; serialize ids and rebuild those.
4. **Let card-targeting Charms and Rites be used in the shop.** They currently only work during a blind, on cards in hand. A "deal 8 random deck cards to choose from" picker would fix it.
5. **Sound and more motion** (card deal, shatter, joker destroyed). Jokers removed mid-hand currently vanish before the replay starts because `play()` finishes before the UI animates.
6. **Optional systems not built:** booster packs, skipping blinds for a reward, permanent shop upgrades, alternate starting decks, difficulty tiers, seeded-run entry in the UI (`?seed=123` in the URL already works).
7. **Known rough edges:** `Understudy` copying a self-destroying joker destroys the original; `Scales` was moved to Legendary because averaging Points and Mult is roughly an 8× boost early on — revisit; emoji fall back to the Noto Color Emoji web font, so art needs either a system colour-emoji font or an internet connection.

## Game rules (as built in core.js)

- 8 antes × 3 blinds (Small ×1, Medium ×1.5, Boss ×2 of the ante base). Ante bases: 300, 800, 2200, 5200, 11000, 21000, 36000, 56000. Beating ante 8's boss wins; endless continues at ×1.6 per ante.
- 52-card deck, hand size 8, play 1–5 cards, 4 hands and 3 discards per blind. Score = Points × Mult.
- 12 hand types with levels (`FH.HANDS`: base pts/mult plus `lp`/`lm` per level). Five of a Kind, Flush House, Flush Five are `secret` (their Decrees only appear once played).
- Money: start $4; blind reward 3/4/6; $1 per unused hand; interest $1 per $5 held (cap $5).
- Shop after every blind: 3 jokers, 3 consumables, reroll $5 (+$1 each). 5 joker slots, 2 consumable slots.
- Card modifiers: enhancements (`heavy keen prism brittle iron gilt charmed granite`), stamps (`crimson azure gold violet`), finishes (`sheen lustre opal`; jokers also `hollow` = +1 slot). Cards also carry permanent `bp` (bonus Points) and `bm` (bonus Mult).
- Three consumable families: **Decrees** level a hand type; **Charms** modify selected cards in hand (enhancement, stamp, finish, suit, rank); **Rites** manipulate the deck (destroy, add, convert random subsets to one suit or rank).

## Engine API (core.js)

Registration:

```js
FH.J(name, rarity /*1-4*/, emoji, desc, flavor, def)   // id = slug(name); cost derived from rarity
FH.C(kind /*'decree'|'charm'|'rite'*/, name, emoji, desc, flavor, def)
FH.B(name, emoji, desc, def)                           // boss
```

Joker `def` fields — every hook is `(c, s, ...extra)` where `c` is the `Ctx` and `s` the joker instance (`s.v` = its state, cloned from `def.v`):

| Hook | When | Extra |
|---|---|---|
| `before` | hand played, before cards score | |
| `retrigger` → number | extra triggers for a scoring card | `card` |
| `onScore` | each time a scoring card triggers | `card` |
| `retriggerHeld` → number, `onHeld` | cards left in hand | `card` |
| `main` | joker's own end-of-hand effect, left to right | |
| `final` | after all jokers | |
| `scored` | `c.total` is set and may be changed | |
| `after` | score added, before cards go to pile | |
| `onDiscard` | `c.discarded`, `c.firstDiscard`; set `c.returnToDraw=true` to recycle | |
| `roll` | on acquire and at every round start (pick per-round suit/rank etc.) | |
| `roundStart`, `firstDraw`, `roundEnd` (`c.boss`) | | |
| `shopEnter`, `shopExit`, `reroll`, `buy` (`item`, fires before the item is added), `sell` (`soldThing`), `sold` (self), `acquired` | | |
| `useCons` (`consDef`), `leveled` (`type`), `cardAdded` (`card`), `cardDestroyed` (`card`, `shattered`), `lucky` (`card`), `interest` (`amount`) | | |
| `rescue` → true | failed the blind; return true to survive | |

Other def fields: `v` (initial state), `mods` (object or `(g,s)=>object` with keys `hands discards handSize jokerSlots consSlots shopJokers interestCap interestRate discount rerollDiscount targetPct debt`), `flags` (array), `copy:(g,s)=>targetInstance` (copy another joker's hooks), `wing:true` (adjacent jokers run `main` one extra time).

Flags the engine understands: `four` (4-card straights/flushes), `gap` (straights skip a rank), `wrap` (K-A-2), `sixNine` (6 = 9 for sets), `colorblind` (H=D, S=C), `crazy8` (8s are every suit), `allFace`, `tenFace`, `allScore`, `noShatter`, `keen2`, `immune` (no debuffs), `luck2` (chances doubled), `luckAll` (chances always hit), `noBoss`, `fav2` (most-played hand +2 levels), `freeFirst` (first discard free), `freeReroll` (first reroll free), `fullSell`, `consKeep` (1 in 4 not used up), `moreRites`, `moreRares`, `firstUncommon`. The UI should also honour `peek` (show top 3 of draw pile).

`Ctx` methods: `pts(n) mult(n) x(n) money(n) msg(text) chance(n,d) has(type) level(type,n) create(kind,id) destroy(card) add(card,'hand'|'draw') kill(joker,text) setPM(p,m,label)`. Fields while scoring: `g played scoring held type lvl first last prevType repeat p m xcount total`. Every effect pushes an event to `c.ev` (`{src, srcKind, kind:'pts'|'mult'|'x'|'money'|'msg'|'start'|'total'|'sync', val, p, m, money}`) which the UI replays as pop-ups.

Game functions: `newGame(seed) startBlind(g) play(g,cards) resolvePlay(g) discard(g,cards) canDiscard(g) winRound(g) enterShop(g) rollShop(g) reroll(g) rerollCost(g) price(g,item) buy(g,item,useNow) sellJoker(g,s) sellCons(g,inst) useCons(g,inst,sel) consError(g,def,sel) leaveShop(g)`. `play` scores but leaves `g.pending` = `'win'|'lose'|'draw'`; the UI animates `res.ev`, then calls `resolvePlay`. Phases: `blind → play → cashout → shop → blind`, or `over`. `g.won` is set when ante 9 is reached.

Helpers: `isSuit(g,card,suit) isFace(g,card) evaluate(g,cards) level(g,type) mostPlayed(g) suitCounts(g) flag(g,f) mod(g,key) handSize maxHands maxDiscards jokerSlots consSlots sellValue addJoker removeJoker createCons destroyCard addCard cloneCard randomCard makeCard pick shuffle sample descOf(def,s)` (replaces `#key#` in desc with `s.v[key]`).

Consumable `def`: `need:[min,max]` selected hand cards (implies in-round), `inRound`, `can(g,sel)` → error string, `use(g,c,sel)`, `hand` (Decrees; id must be `decree_<handId>` because Azure Stamps create them by id). Boss `def`: `debuff(card,g)`, `mods`, `targetMult`, `validate(g,cards)` → error, `onStart(g,c)`, `onPlay(g,c)` (may set `c.nulled`), `afterPlay(g,c)`, `faceDown(g,card)`, `noReward`, `finale` (ante 8 pool), `min` ante. The engine special-cases boss id `the_censor` (all hands count as level 1).

## Uniqueness rule for jokers

No two jokers may be the same template with a number, suit, rank or hand name swapped. `test/check.js` should normalize every description (digits → N, suit names → SUIT, rank names → RANK, hand names → HAND) and assert all 300 are distinct. Use only single-codepoint emoji from Unicode 12 or earlier (no ZWJ sequences, no U+FE0F), one unique emoji per joker.

## UI plan

- Look: a variety theatre at night. Aubergine curtain `#2B1638` with a faint harlequin diamond pattern, paper cards `#FBF3DC` with ink `#231532`, footlight gold `#F2C14E` (money), Points blue `#4DB6E8`, Mult rose `#FF5D73`, mint `#6FD3A8` for the Play button. Fonts: Limelight (display) and Alegreya Sans (text) from Google Fonts with fallbacks.
- Layout: left playbill panel (blind, target, round score, hand preview Points × Mult, hands/discards/money, ante); top shelf of jokers and consumables; centre stage (blind select / played cards / cash-out / shop); bottom hand with Play, Discard and sort buttons, deck count.
- Tooltips for jokers, cards, consumables (name, description with coloured numbers, flavor, rarity). Modals: full deck, hand levels, collection of all 300 jokers, game over, victory.
- Drag to reorder jokers and hand cards (dragging the hand sets `g.sortMode = null`).
- Scoring: call `FH.play`, replay `res.ev` as pop-ups on `[data-uid]` elements while updating the Points/Mult counters, then `FH.resolvePlay`.
- Joker art: `FH.art(def)` returns an inline SVG — hashed gradient, one of ~10 background patterns, one of ~8 halo shapes, the joker's emoji large in the centre.
